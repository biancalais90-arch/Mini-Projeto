Sobre o projeto

O projeto simula o retorno de uma API por meio de uma lista de mapas (List<Map<String, dynamic>>), converte esses dados em objetos da classe Tarefa e gera relatórios com base nos status das tarefas.

Funcionalidades implementadas
Conversão de mapas em objetos.
Tratamento de dados nulos.
Remoção de espaços extras com trim().
Conversão de valores monetários para double.
Exibição das tarefas convertidas.
Identificação dos status existentes.
Cálculo do valor total das tarefas concluídas.
Cálculo da média de valor das tarefas pendentes.
Cálculo do total de horas por status.
Identificação de tarefas com dados incompletos.
Geração de relatório final consolidado.
Aplicação de herança, polimorfismo e encapsulamento.
Estrutura de Branches
main

Branch principal contendo a versão estável do projeto.

develop

Branch utilizada para integração das funcionalidades.

feat/conversao-dados

Implementação da conversão dos dados simulados para objetos da classe Tarefa.

feat/relatorio-tarefas

Implementação dos cálculos, filtros e relatório final.

docs/readme-video

Documentação do projeto e materiais de apresentação.

Estruturas utilizadas
List

Utilizada para armazenar os dados simulados e a lista de tarefas convertidas.

Map

Utilizado para representar os dados recebidos da API simulada.

Set

Utilizado para identificar os status únicos encontrados nas tarefas.
